请使用 Motion Canvas 实现一个 Rust 所有权科普短视频。

要求：

- 画面比例：1080×1920，竖屏；
- 总时长约 60—70 秒；
- 深色背景；
- 使用简单 Pictogram 表示小明和张三；
- 小明使用蓝色，张三使用红色；
- 钥匙使用黄色；
- 代码使用等宽字体；
- 每个镜头单独建立 scene；
- 优先复用 Rect、Txt、Line、Code、Layout；
- 使用 waitUntil 标记关键旁白节点；
- 不要使用难理解的边缘约束绑定；
- 优先使用 Layout 或明确的 x/y 坐标；
- Move 动画中始终只有一把钥匙；
- Borrow 动画中正式钥匙不能离开小明；
- 不要一次性实现全部镜头，先完成镜头一和镜头二；
- 完成后运行类型检查，并修复所有错误。
